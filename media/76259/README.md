# Fécamp — objectif quantitatif de 120 récits

Ce paquet conserve les 9 récits existants de Git et propose 111 nouveaux textes. IMPORTANT : l’objectif de 120 récits **éditorialement achevés** n'est pas vérifié : beaucoup sont des amorces fondées sur des index d’études, et non des récits de 2-3 minutes intégralement expertisés. Ne pas confondre couverture et validation factuelle complète.

Photos : liens Wikimedia Commons **uniquement**, aucune photo embarquée, aucun téléchargement en simulation ni publication. `placement_images.json` est un registre de médias distant ; sa présence n'implique pas que l'app iOS sache afficher les images en ligne.

Les 9 récits existants restent strictement identiques ; ajout sans écrasement si empreinte Git conforme. Aucun document hors Fécamp n'est modifié, hormis l'entrée index de Fécamp. `--publier` publie réellement après tous les contrôles ; vérifier la qualité de chaque texte avant exécution.
