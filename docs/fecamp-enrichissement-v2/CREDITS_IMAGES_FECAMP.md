## Licences et obligations
- **CC BY-SA 3.0** : https://creativecommons.org/licenses/by-sa/3.0/ — attribution, lien vers la licence, indication des modifications, partage dans les mêmes conditions pour toute adaptation.
- **CC BY-SA 2.0** : https://creativecommons.org/licenses/by-sa/2.0/ — obligations comparables de crédit et de partage à l’identique.
- **Domaine public / PD-Art** : https://commons.wikimedia.org/wiki/File:Abb%C3%A9_Pr%C3%A9vost.jpg — description originale indiquant une photographie fidèle d'une œuvre bidimensionnelle déjà dans le domaine public. Les éventuelles limites selon juridiction restent précisées sur Commons.
- L’objet `image` dans chaque JSON reprend les propriétés `commons`, `page`, `credit`, `license`, `caption`, `alt` utilisées par les fiches existantes.
- Les images sont ici référencées à l'aide des **noms réels des fichiers Commons**; le champ `page` pointe vers leur page de description et non vers une copie sans crédit.
