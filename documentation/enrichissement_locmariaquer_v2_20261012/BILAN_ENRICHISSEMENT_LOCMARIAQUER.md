## Nouvelles anecdotes (indices 12 à 15)
- **12 — Notre-Dame de Kerdro : du navire sauvé à la statue reconstruite** (histoire) : Une apparition aurait évité un naufrage. La statue érigée en souvenir fut ensuite détruite pendant la guerre, avant de renaître. Source : https://paroisse-locmariaquer.fr/paroisse-locmariaquer-histoire-de-la-paroisse/. Illustration : non ; absence motivée dans le document de crédits.
- **13 — Coët-Courzo : le moulin à marée qui s'électrifia** (economie) : Un moulin fonctionnait déjà ici au XVIe siècle. Après des siècles rythmés par la marée, il utilisa aussi l'électricité à partir de 1937. Source : https://www.patrimoine.bzh/gertrude-diffusion/dossier/IA56132061. Illustration : Commons 051 Moulin de Coët Courzo Locmariaquer.jpg.
- **14 — Le secret des champs disparus dans la tourbe de Kerpenhir** (prehistoire) : Une tourbière à peine visible à marée très basse révèle des pollens de céréales et les premières transformations agricoles du paysage. Source : https://archeologie.culture.gouv.fr/megalithes/fr/avant-les-megalithes-0. Illustration : non ; absence motivée dans le document de crédits.
- **15 — Saint-Michel : les antiquités romaines sous la chapelle de Robien** (patrimoine) : Une chapelle reconstruite au XVIIIe siècle recouvre un secteur antique que le marquis de Robien examinait déjà avec curiosité. Source : https://paroisse-locmariaquer.fr/chapelle-saint-michel/. Illustration : Commons W1554-Locmariaquer StMichel 1818 80899.JPG.
