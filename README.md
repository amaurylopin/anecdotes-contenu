# anecdotes-contenu

Fiches rédigées pour l'application Anecdotes, un fichier JSON par commune : `communes/<code INSEE>.json`.
Textes rédigés à la demande de l'auteur, sources publiques (Wikipédia, base Mérimée, Gallica, Wikidata), lien de source sur chaque article.
Aucune donnée d'utilisateur. L'application lit ces fichiers tels quels ; `index.json` liste les communes couvertes.
